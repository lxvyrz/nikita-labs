# EMPIRE — Business Tycoon

A premium-style, self-contained idle business simulator. Built with vanilla HTML, CSS and JavaScript; no dependencies or accounts.

## Play in seconds
Download **EMPIRE-Open-Me.html** and double-click it. Chrome, Edge and Firefox can run it directly as a local file. Do not use GitHub's Raw page to play; GitHub displays source text.

## Gameplay
- Begin with £0. Click **Work for Cash** for £5 per click.
- Purchase ten escalating businesses, from Lemonade Stand to Space Corporation.
- Businesses generate passive income every second.
- Upgrade **Hustle Training** for 2× click income, **Global Marketing** for 1.5× passive income, and **Operations Team** to improve offline earning duration and efficiency.
- Prestige after earning £1 million in a run for permanent Legacy Points (+10% passive income each).
- Rank up from Hustler to Billionaire based on net worth.
- Earnings accrue while playing; when reopening after time away, the game awards limited offline earnings.
- Autosaves to localStorage. Export or import a JSON backup; reset is available in the Save panel.

## Privacy
No accounts, real money, purchases, network requests, or online leaderboards. Save data stays in the browser profile and can be lost if browser storage is cleared.

## Technical note
JavaScript syntax has been checked, but full interactive browser testing has not been performed. If something doesn't work, report which button or action failed.
