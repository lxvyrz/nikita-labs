# NIGHTSHIFT — Highway Racer

A neon arcade highway racer in a **single HTML file**. No installation, server, account, or dependencies required.

## Launch
1. Open **NIGHTSHIFT-Open-Me.html** on GitHub.
2. Click the **Download** icon (not **Raw**).
3. Double-click the downloaded file to play locally in Chrome, Edge or Firefox.

## Controls
- **Left / Right arrows** or **A / D**: change lane
- **Up arrow / W**: accelerate
- **Down arrow / S**: brake
- **P**: pause / resume
- Touch-friendly steering, gas and brake buttons beneath the game

## Gameplay
- Dodge procedurally spawned traffic on a four-lane night highway.
- Score points by driving and passing cars; close passes give near-miss bonuses.
- Earn in-game cash per kilometre and through near misses.
- Unlock four cars with increasing top speeds and acceleration.
- Adjust traffic density, toggle sound, and track your best score, distance and near misses.
- Wallet, garage and records save to your browser automatically.
- Crashes end the current run, but earnings remain in your wallet.

## Notes
- This is a stylised top-down 2D arcade game, not a 3D driving simulator.
- The JavaScript has passed a syntax check, but interactive browser playtesting was not available during creation.
- The game uses no external libraries, music, images or network calls.
