# KNIGHTLY — Play Chess

A standalone, chess-inspired browser website made for Nikita Labs. Independent of and not affiliated with Chess.com.

## Launch
Download **KNIGHTLY-Open-Me.html** from GitHub and double-click it to play in a modern browser. No installation or internet connection required.

## Features
- Interactive chessboard with click-to-move and legal-move indicators
- Play vs a built-in computer opponent (Casual, Intermediate, Challenging) or a friend on the same device
- Castling, en passant, pawn promotion, check/checkmate, stalemate, threefold repetition, fifty-move rule and basic insufficient-material detection
- 3-, 10-, 15-minute or unlimited time controls
- Undo, flip board, resign, restart and copy move history

## Limitations
- The built-in computer uses lightweight search, not a professional chess engine.
- No real-time multiplayer, accounts, rating system, or cloud storage.
- Move notation is simplified rather than full disambiguated SAN.
- JavaScript syntax was checked, but full interactive browser testing was not completed.
