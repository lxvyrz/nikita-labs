# PULSE — One Button Rhythm Game

Play locally by downloading **PULSE-Open-Me.html** and double-clicking it in Chrome, Edge or Firefox. This file is self-contained; no installation, hosting or dependencies required.

## Controls

- **Space** or **Enter**: Hit the next checkpoint as the orbiting pulse reaches it
- **Tap/click the arena**: Alternative input
- **P**: Pause or resume

Choose one of three procedural tempo tracks (100, 135, 165 BPM), difficulty, and session duration. Timing windows are 130ms, 92ms, or 60ms. A successful hit gives Perfect, Great, or Good based on timing. Missed beats reset the combo. Records are saved to browser localStorage per track/difficulty/duration combination. Music and hit sounds are synthesised with Web Audio after user interaction; sound can be disabled.

## Notes

This is an original circular checkpoint rhythm mechanic inspired by one-button rhythm games, not a copy of another game's songs or assets. The game is designed for desktop but supports touch. There is no account, server, tracking, or external asset requirement (the optional Google font has a system fallback).

The game has been committed to GitHub but has not been tested in an interactive browser in this session.
